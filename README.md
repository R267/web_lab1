# Лабораторна робота № 1 — Засоби побудови веб-сторінок

Адаптивні веб-сторінки для п'яти макетів (а–д), кожен виконано двома способами:
розмітка за допомогою **таблиці** та розмітка за допомогою **блоків (div)**.

## Структура проєкту

```
lab1/
├── index.html          — меню для переходу до всіх макетів
├── css/
│   ├── base.css        — спільні стилі: кольори, hover-ефекти блоків, типографіка
│   ├── table.css       — розмітка таблицею
│   └── div.css         — розмітка блоками (flex + CSS Grid)
├── table/              — variant-a … variant-d (розмітка таблицею)
├── div/                — variant-a … variant-d (розмітка блоками)
└── img/                — схеми макетів із завдання
```

Літери: a — а), b — б), v — в), g — г), d — д).

## Запуск

Відкрити `index.html` у браузері (жодних залежностей не потрібно).

## Вивантаження в git-репозиторій

git remote add origin <URL вашого репозиторію>
