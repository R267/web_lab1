Основи веброзробки: HTML та CSS

HTML (HyperText Markup Language) — це мова розмітки гіпертексту, яка визначає структуру вмісту веб-сторінки. За допомогою спеціальних тегів браузер розуміє, де заголовок, де абзац, а де список чи посилання.

CSS (Cascading Style Sheets) — каскадні таблиці стилів, які відповідають за зовнішній вигляд сторінки: кольори, шрифти, відступи, розташування елементів. Розділення структури (HTML) і оформлення (CSS) робить сторінки простішими у підтримці.

Нижче наведено перелік основних переваг використання CSS для оформлення сторінок:

  • єдина таблиця стилів керує оформленням багатьох сторінок;
  • точний контроль над зовнішнім виглядом елементів;
  • адаптивність під різні пристрої та розміри екрану;
  • зменшення обсягу коду та спрощення підтримки проєкту.
